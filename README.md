# CodeAlpha Python Programming Tasks

This repository contains two completed projects for the **CodeAlpha Python Programming Internship**.

## Completed Tasks

### Task 2: Stock Portfolio Tracker

A Python console program that uses manually defined stock prices. The user enters stock symbols and quantities, and the program calculates individual investment values and the total portfolio value. The result can also be saved to a CSV file.

Folder: `Task_2_StockPortfolioTracker`

### Task 3: Email Extractor Automation

A Python automation script that reads a text file, extracts email addresses using regular expressions, removes duplicates, displays the results, and saves the unique email addresses to another text file.

Folder: `Task_3_EmailExtractorAutomation`
